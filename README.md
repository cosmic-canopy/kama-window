# @kama/window

A window and its events, for [kama](https://kama-lang.org): several windows and a headless mode, one coalescing event
queue, physical keys and text, an explicit `pump()`, and gamepads.

**Status: the native window (Windows) and the headless one work, not yet published.** The web window and gamepads
come next (`AGENTS.window.md`). The design is kama's (its `docs/ROADMAP_DETAIL.md` § 8, KR-26), and kyoten builds it
as its first consumer.
